# Petale — студія манікюру

Простий односторінковий сайт-лендинг студії манікюру: послуги й ціни, переваги, галерея, онлайн-запис і контакти.

Статичний сайт без збирання: HTML + CSS + трохи JS. Деплой — Vercel з гілки `main`.

## Що заповнити перед запуском
- Телефон, Telegram, Viber, Instagram — у блоці «Контакти» в `index.html`, в `CONFIG` унизу `index.html` і в JSON-LD у `<head>`.
- Адреса та графік — там само.
- `formEndpoint` у `CONFIG` (напр. Formspree), щоб заявки приходили на пошту.
- Дані власника в `privacy.html` (виділені жовтим).
